# Legura Working Rules

- Read README.md and docs/roadmap.md before expanding scope.
- Keep CMS product behavior here and reusable framework fixes in Axonyx.
- Preserve unrelated changes. Do not rewrite generated output by hand.
- Feature PRs target dev; release PRs move dev to main.
- No secrets, production database credentials, or user data in Git.
- Do not advertise planned commands, database adapters, or installers as shipped.
- Test real authorization and data persistence, not only rendered UI.
- Keep Docker optional and native installation first-class.
