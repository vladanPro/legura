# Legura 0.0.3 Pilot 1

Experimental self-hosted CMS pilot for evaluation, not a stable production
release or an automatic upgrade.

## Included

- Administrator-managed Editor and Subscriber accounts, search and role/status filters.
- Account deactivation/reactivation with persistent session revocation.
- Current-password-confirmed administrator Profile password changes.
- Aegis browser coverage with page scripts enabled and disabled, including mobile Users layouts.
- Verified native packages, backup recovery and candidate-derived schema upgrade checks.

## Downloads

- Windows x64 ZIP with its matching SHA-256 file.
- Linux x64 TAR.GZ with its matching SHA-256 file, tested on Ubuntu 24.04.
- GitHub's source ZIP/TAR.GZ for developers who want to modify and rebuild Legura.

Extract native packages into a NEW directory, compare the archive with its
checksum, and follow the included README. The native packages contain no
database, credentials or application source and do not require Rust, Cargo,
Node.js or Docker at runtime. Packages and checksums are unsigned.

## Existing Installations

Back up and verify both the database and referenced media before attempting
an upgrade. Rehearse on an inactive copy and preserve the original installation.
Do not overwrite a running package, database, configuration or media directory.

The 0.0.3 backup reader accepts producer versions 0.0.1, 0.0.2 and 0.0.3.
Reading an older archive does not migrate its schema or authorize activation.
Older readers reject backups written by 0.0.3.

This release includes migrations through 019. Existing installations need a
separate verified migration/cutover procedure; replacing executable files alone
does not upgrade a database. There is no automatic update, email password reset,
public registration, PostgreSQL/MySQL product support or plugin marketplace.
