# Legura 0.0.6 Pilot 1 Candidate

This prepares a native pilot download, not a stable release. Publish only
after promotion to main and verification of the Linux and Windows artifacts.

## Included

- Public post and page details render titles and descriptions in the HTML head.
  Canonical links use the configured Site Address; drafts and admin pages do
  not expose public content metadata.
- The native server uses Axonyx Runtime 0.8.7 with the updated TLS root store.
  Source pilot checks use cargo-axonyx 0.8.13.

## Upgrade and Recovery

No migration is added in this pilot. The 0.0.6 reader accepts backups produced
by 0.0.1 through 0.0.6. Use the pre-upgrade backup and prior package for
rollback; older binaries do not accept archives created by 0.0.6.

Rehearse with unconfigured copies of the published 0.0.5 package and the
new candidate before changing a live installation:

```powershell
python -B scripts/smoke-schema-upgrade.py PATH_TO_PRIOR PATH_TO_CANDIDATE --runtime-refresh
```

The rehearsal checks zero migrations, existing login, authorship, media,
draft privacy, and public metadata after editing and publishing the restored
post. It verifies that the stopped source and its backup were not changed.
