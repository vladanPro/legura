# Legura 0.0.5 Pilot 1 Candidate

This is release preparation, not a published download or a stable production
release. Publish only after full release CI and promotion from dev to main.

## Included

- Classic, Alloy, and Legura themes for the public site. Activate a theme in
  **Appearance**; the administration panel keeps its own appearance.
- Theme cards use the saved public Light/Dark mode and palette. **Theme default**
  shows Silver for Classic and Bronze for Alloy and Legura.
- The active card is marked with an **Active theme** badge. Viewing the catalog
  does not activate a theme or change content.

## Upgrade and Recovery

Migration 021 preserves the existing layout choice, color mode, and palette.
Classic and Alloy retain the historical `default` and `editorial` identifiers.
An active Legura theme cannot be represented by the old schema: switch to
Classic or Alloy before rehearsing a schema downgrade. This does not make a
newer backup readable by an older release.

The 0.0.5 reader accepts backup producer versions 0.0.1 through 0.0.5.
Older binaries do not accept 0.0.5 backups. Keep the pre-upgrade archive and
source package. Rehearse on an inactive copy before switching configuration;
no automatic update, downgrade, or production migration is included.

## Release Gates

- Full registry CI and native Linux/Windows packaging.
- Isolated theme activation, preview, and restart checks.
- Upgrade rehearsal from the published 0.0.4 pilot: preserve
  Alloy/Dark/Gold, verify recovery with Legura active, and prove the prior
  database and backup are unchanged.
